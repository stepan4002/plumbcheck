02 / TAKE IT TO YOUR REPO

From one bug to a regression test.

How does it test different agents?

MCP agents: connect your client to PlumbCheck's fixture server. Your agent chooses the calls; the server checks their arguments, order, policies, and results. In the Windows app, open Contract to save a test case and generate the MCP configuration.

JavaScript agents: pass the replay client into your function, or use the CLI's --agent runner to check its final output too.

Other frameworks, Python, and workflow builders: use their MCP support when available, or write an adapter for their tool interface. Framework-specific adapters and automatic workflow imports are not included yet.

PlumbCheck checks intercepted calls. Disconnect your client's live tool servers for a fixture test; unrelated tools, model reasoning, and other agent I/O are outside this boundary.

01. Run it locally

The Windows app bundles its runtime. For the source-code version, use Node.js 22 or later:

npm test
npm start

# Intentional failure, exit code 1
npm run demo

# Corrected contract, exit code 0
npm run check

02. Gate a pull request

Commit a synthetic or reviewed fixture. Run a contract in CI and keep the evidence as a build artifact.

node bin/plumbcheck.js run \
  examples/customer-support/safe.json \
  --out reports/ci

Outputs HTML, masked JSON, and JUnit XML. Exit codes: 0 passed, 1 failed, 2 invalid input.

03. Exercise your agent code

Pass a ReplaySession wherever your agent accepts a client with callTool({ name, arguments }). Then verify all fixtures were consumed.

const client = new ReplaySession({
  fixtures, policies, context
});
await yourAgent(client);
client.verifyComplete();

See the runnable examples/customer-support/agent.js.

04. Know the boundary

Replay makes zero live tool calls. Recording through a real client executes real tools. Tool names and arguments match exactly; unknown tools and missing fixtures fail.

PlumbCheck is a testing layer. It is not a sandbox, an approval service, or a guarantee of deterministic LLM behavior.
